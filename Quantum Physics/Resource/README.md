## Environment

Seluruh kode pada lesson dapat dijalankan di:

- **Google Colab** (tanpa instalasi): <https://colab.research.google.com/>
- **Lokal**: Python 3.10+ lalu `pip install numpy matplotlib jupyter`

Mulai Lesson 05, kita akan menggunakan **Qiskit** dan/atau **QuTiP**.

## Cara Belajar

1. Baca **Learning Materials** secara berurutan; kerjakan contoh perhitungan di kertas.
2. Jalankan **Guided Practice** di notebook Anda sendiri — ubah parameter dan amati hasilnya.
3. Kerjakan **Assignment** yang direferensikan di akhir lesson.
4. Tulis jawaban **Self-Reflection** dan bawa pertanyaan Anda ke meeting.
