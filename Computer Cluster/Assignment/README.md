## Cara Pengumpulan

1. Buat satu folder per assignment, contoh: `assignment-01/`, `assignment-02/`.
2. Ikuti struktur file pada bagian **Deliverables** di setiap assignment.
3. Gunakan format Markdown (`answers.md`) untuk jawaban. Tulis command di dalam code block:

   ````markdown
   ```bash
   ls -la ~
   ```
   ````

4. Kumpulkan sesuai instruksi mentor sebelum deadline.

## Aturan

- Kerjakan secara mandiri. Diskusi diperbolehkan, tetapi jawaban dan script harus ditulis sendiri.
- Penggunaan AI/LLM diperbolehkan **untuk belajar**, bukan untuk menyalin jawaban. Anda harus mampu menjelaskan setiap command yang Anda tulis saat meeting.
- Jika menemui kendala, catat error yang muncul dan langkah yang sudah dicoba — ini akan dibahas pada meeting.
