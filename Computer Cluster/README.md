# Computer Cluster COMICS Study Group 2026

Study Group Computer Cluster merupakan bagian dari COMICS Study Group 2026 yang berfokus pada fundamental Linux, computer networking, cluster computing, workload management, dan computational workflow.

## Learning Goal

Setelah mengikuti program ini, peserta diharapkan mampu:

* Menggunakan Linux melalui command line.
* Memahami filesystem, process, dan resource pada Linux.
* Menggunakan SSH untuk mengakses remote computer.
* Memahami konsep dasar jaringan komputer.
* Memahami arsitektur computer cluster.
* Menggunakan SLURM untuk menjalankan computational workload.
* Membuat batch job dan melakukan monitoring job.
* Memahami parameter sweep dan parallel computing.
* Menjalankan computational project pada cluster.

## Learning Method

Pembelajaran dilakukan menggunakan pola:

**Self-study → Meeting → Self-study → Meeting**

Peserta mempelajari materi melalui `Resource/`. Pada meeting, materi dibahas kembali melalui penjelasan, demonstrasi, hands-on practice, troubleshooting, dan evaluasi.
