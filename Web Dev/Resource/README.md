## Tools

## Cara Belajar

1. Baca **Learning Materials** secara berurutan.
2. Ketik ulang (jangan copy-paste) kode di **Guided Practice**, lalu ubah-ubah untuk melihat efeknya.
3. Kerjakan **Assignment** yang direferensikan di akhir lesson.
4. Tulis jawaban **Self-Reflection** dan bawa pertanyaan Anda ke meeting.
