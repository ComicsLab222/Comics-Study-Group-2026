# Web Development — Study Group 2026

Study Group Web Development merupakan bagian dari COMICS Study Group 2026 yang berfokus pada fundamental web development hingga pengembangan aplikasi web sederhana dengan frontend, backend, database, dan API.

## Learning Goal

Setelah mengikuti program ini, peserta diharapkan mampu:

* Memahami cara kerja web dan client-server architecture.
* Membuat halaman web menggunakan HTML dan CSS.
* Memahami fundamental JavaScript.
* Menggunakan Git dan GitHub dalam software development.
* Memahami backend dan application architecture.
* Membuat REST API sederhana.
* Menggunakan database dan operasi CRUD.
* Menghubungkan frontend, backend, API, dan database.
* Mengembangkan mini project web secara terstruktur.

## Learning Method

Pembelajaran dilakukan menggunakan pola:

**Self-study → Meeting → Self-study → Meeting**

Materi pada `Resource/` digunakan untuk self-study. Meeting digunakan untuk menjelaskan kembali materi, melakukan coding practice, membahas permasalahan, dan mengevaluasi hasil belajar.
