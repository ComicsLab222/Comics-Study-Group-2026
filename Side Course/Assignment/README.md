# 📝 Assignment — Side Course

Kumpulan tugas praktis untuk menguji pemahaman dan keterampilan teknis pada modul pendukung [`Resource/`](../Resource/README.md).

## Daftar Assignment

| No | Assignment | Modul Terkait | Fokus Deliverables |
| -- | ---------- | ------------- | ------------------ |
| 01 | [Git & GitHub](Assignment-01-Git-GitHub.md) | [Lesson 01](../Resource/Lesson-01-Git-GitHub.md) | Akun GitHub, SSH Setup, First Public Repo, Branch & PR, `.gitignore` |
| 02 | [LaTeX & Markdown](Assignment-02-LaTeX-Markdown.md) | [Lesson 02](../Resource/Lesson-02-LaTeX-Markdown.md) | Markdown Cheat Sheet, Formula Matematika & Matriks LaTeX, Report Template |

## Cara Pengumpulan

1. Buat folder tugas mandiri dengan format:
   - `assignment-01/` untuk tugas Git & GitHub.
   - `assignment-02/` untuk tugas LaTeX & Markdown.
2. Ikuti spesifikasi struktur file pada bagian **Deliverables** di masing-masing assignment.
3. Kumpulkan file Markdown (`answers.md`) beserta screenshot pendukung sesuai panduan mentor.

## Nilai Tambah

Keterampilan yang Anda kuasai di modul ini akan menjadi standar format pengumpulan tugas pada ketiga track utama:
- Penulisan laporan format Markdown yang rapi dan konsisten.
- Penulisan formula kuantum menggunakan sintaks LaTeX.
- Manajemen riwayat pengerjaan proyek dan pull request di GitHub.
