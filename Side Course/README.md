# Side Course — COMICS Study Group 2026

**Side Course** merupakan modul pendukung yang dirancang untuk membekali seluruh peserta COMICS Study Group 2026 dengan keterampilan fundamental dalam rekayasa perangkat lunak, sistem kontrol versi, dokumentasi teknis, dan penulisan saintifik.

Modul ini mendukung langsung pengerjaan tugas dan proyek pada ketiga track utama:
- ⚛️ **Quantum Physics**: Penulisan persamaan matematika, bra-ket, dan matriks operator menggunakan LaTeX di Markdown.
- 🖥️ **Computer Cluster**: Manajemen kode, shell scripting di repositori Git, dan pelaporan analisis komputasi.
- 🌐 **Web Development**: Version control, kolaborasi tim melalui branching & Pull Request di GitHub.

---

## 📌 Topik Pembelajaran

### 1. [Git & GitHub](./Resource/Lesson-01-Git-GitHub.md)
Membahas konsep version control hingga alur kerja kolaboratif di cloud:
* Konsep Version Control System (VCS) vs GitHub.
* Pembuatan dan konfigurasi akun GitHub yang aman (profil & 2FA).
* Instalasi dan setup Git di mesin lokal (identitas & default branch).
* Konfigurasi autentikasi modern menggunakan **SSH Key** dan Personal Access Token (PAT).
* Siklus kerja Git: inisialisasi, staging (`git add`), commit, remote, dan push.
* Praktik penggunaan `.gitignore` untuk melindungi file sensitif.
* Alur kolaborasi profesional: **branching**, commit terisolasi, **Pull Request (PR)**, code review, dan merge.

👉 *Lihat [Materi](./Resource/Lesson-01-Git-GitHub.md) · [Assignment](./Assignment/Assignment-01-Git-GitHub.md)*

### 2. [LaTeX & Markdown](./Resource/Lesson-02-LaTeX-Markdown.md)
Membahas teknik penulisan dokumentasi teknis dan formula saintifik berstandar industri:
* Konsep Markdown untuk dokumentasi ringan dan LaTeX untuk typesetting saintifik.
* Formatting teks lengkap: heading, bold, italic, strikethrough, quote/callout, list bertingkat, task list, dan tabel.
* Code formatting: inline code dan fenced code block dengan syntax highlighting.
* Integrasi LaTeX ke Markdown via MathJax / KaTeX (inline math `$ ... $` dan block math `$$ ... $$`).
* Penulisan formula matematika: pecahan, pangkat/subskrip, akar, limit, integral, sumasi.
* Notasi mekanika kuantum: matriks Pauli ($2 \times 2$), notasi Dirac bra-ket ($|\psi\rangle$), dan persamaan multi-baris sejajar (`\begin{aligned}`).
* Desain template laporan teknis yang rapi dan standar untuk submission tugas.
