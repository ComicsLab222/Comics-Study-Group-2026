# 📚 Resource — Side Course

Materi pembelajaran pendukung untuk membekali peserta COMICS Study Group 2026 dengan keterampilan dasar rekayasa perangkat lunak, dokumentasi teknis, dan saintifik.

Setiap modul disusun dengan struktur konsisten:
`Learning Objectives → Prerequisites → Learning Materials → Guided Practice → Assignment → Self-Reflection → Further Reading`

## Modul Tersedia

| No | Modul | Topik Utama | Assignment Terkait |
| -- | ----- | ----------- | ------------------ |
| 01 | [Git & GitHub](Lesson-01-Git-GitHub.md) | Akun GitHub, Instalasi & Setup Lokal, Credentials/SSH, Commit & Push, Pull Request | [Assignment 01](../Assignment/Assignment-01-Git-GitHub.md) |
| 02 | [LaTeX & Markdown](Lesson-02-LaTeX-Markdown.md) | Formatting Markdown, Integrasi LaTeX, Rumus Matematika, Matriks, Bra-Ket | [Assignment 02](../Assignment/Assignment-02-LaTeX-Markdown.md) |

## Cara Menggunakan Materi Ini

1. **Pelajari Sesuai Kebutuhan**: Modul ini dapat dipelajari secara mandiri kapan saja, terutama di awal minggu program (8–21 Oktober 2026), sebelum pengumpulan tugas-tugas utama.
2. **Praktik Langsung**: Buka terminal dan text editor (VS Code) untuk langsung mencoba setiap baris perintah dan contoh kode yang diberikan di bagian **Guided Practice**.
3. **Gunakan untuk Tugas Track Utama**:
   - Kemampuan **Git & GitHub** akan langsung digunakan untuk submit kode dan kolaborasi di track **Web Dev** dan **Computer Cluster**.
   - Kemampuan **LaTeX & Markdown** akan langsung digunakan untuk menuliskan jawaban matematis pada track **Quantum Physics** dan laporan teknis pada track **Computer Cluster**.
